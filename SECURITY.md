# Security Policy for Sage

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The Sage team takes security and user privacy seriously.

If you discover a security vulnerability in Sage:

1. Please do **NOT** open a public issue.
2. Email details directly to [diamond](diamondosazuwa@gmail.com)
3. Include steps to reproduce, affected versions, and any suggested patches.

We will acknowledge receipt within 48 hours and work with you to patch and coordinate responsible disclosure.
